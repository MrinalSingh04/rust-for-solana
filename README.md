## Rust Primitive Data Types

This lesson demonstrates basic Rust data types using blockchain-style examples.

Covered types:
- Integers (`u128`, `i64`)
- Floating point (`f32`, `f64`)
- Boolean (`bool`)
- Character (`char`)
- String types (`&str`, `String`)

The examples use concepts like token supply, transaction fees, wallet addresses, and contract names to make them relevant for Solana and Web3 development.
